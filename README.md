Customer Shopping Behaviour Analysis
1. Project Approach
The objective of this project is to analyse customer shopping behaviour and understand purchasing patterns across different customer groups. The analysis focuses on gender, age groups, product categories, revenue, quantity sold, payment methods, and shopping malls.

The project was carried out using the following steps:
1.	Data Collection: Imported the customer shopping dataset for analysis.
2.	Data Cleaning: Checked the dataset for missing values, duplicate records, and incorrect data formats.
3.	Data Preparation: Organised the data and created a new Revenue column using the formula:
   
Revenue = Quantity × Price
5.	Exploratory Data Analysis (EDA): Analysed shopping patterns based on gender, age, product category, and payment method.
6.	Data Visualisation: Created charts, graphs, and KPI cards using Power BI.
7.	Insights and Recommendations: Identified important shopping trends and suggested ways to improve business performance.
2. Dataset Description
The project uses a customer shopping behaviour dataset containing shopping transactions from different malls in Istanbul, covering the period 2021–2023.
The dataset contains 99,457 records and 10 columns.
Column	Description
invoice_no	Unique invoice number
customer_id	Customer identification number
gender	Customer gender
age	Customer age
category	Product category
quantity	Number of items purchased
price	Price per unit in Turkish Lira (TL)
payment_method	Method of payment
invoice_date	Date of transaction
shopping_mall	Name of the shopping mall
 Tools and Models Used

Tools used:
•	Microsoft Excel: Data cleaning, calculations, and initial data analysis.
•	SQL: Data querying, filtering, grouping, and summarising records.
•	Power BI: Dashboard creation, KPI cards, charts, and interactive visualisations.

Analytical methods used:
•	Descriptive analysis to understand customer shopping patterns.
•	Exploratory Data Analysis (EDA) to identify trends and relationships.
•	Aggregation and grouping to compare sales across customer segments.
•	Revenue analysis using Quantity × Price.
•	Comparative analysis by gender, age group, product category, and payment method.

Note: This project uses descriptive and exploratory analytical methods. No machine-learning prediction model was used.

 Conclusions
The project helps understand customer purchasing behaviour and provides insights into sales performance.

The analysis focuses on:
•	Comparing shopping distribution between male and female customers.
•	Identifying which gender purchases more products and generates more revenue.
•	Understanding which age groups contribute more to product sales and revenue.
•	Identifying popular product categories.
•	Analysing payment method preferences.
•	Comparing shopping behaviour across different shopping malls.

 Business Recommendations
1.	Focus marketing campaigns on customer segments that contribute strongly to sales.
2.	Promote popular product categories through offers and discounts.
3.	Develop targeted promotions for different age groups.
4.	Review payment preferences and provide convenient payment options.
5.	Monitor shopping mall performance to identify opportunities for improvement.
6.	Use the Power BI dashboard regularly to track sales and customer behaviour.

 Final Conclusion
This project demonstrates how Excel, SQL, and Power BI can be used together to analyse customer shopping behaviour. The analysis converts raw transaction data into meaningful business insights and helps businesses understand customers, monitor sales performance, and make data-driven decisions.
